## Selenium - QA Automation Hands-on Questions

## Q1. Write a working executable code using any programming language like Python, Java, etc. using Selenium to automate below test steps:

1. Open "https://www.google.com/" in Chrome browser.
2. Make chrome browser window in full screen mode
3. Fetch the Google logo image's location on screen and its size using Selenium
4. Check if this Google logo is clickable or not.
5. If Google logo is clickable then click on it, else write "Not clickable" in the search textbox.

## Q2. Write a working executable Selenium program to:

1. Open "https://www.facebook.com/" in Chrome.
2. Maximize the browser window.
3. Find the Facebook logo and fetch its location and size.
4. Check whether the logo is displayed and enabled.
5. If the logo is clickable, click it; otherwise, enter "Not clickable" in the email textbox.

## Q3. Write a working executable Selenium program to:

1. Open "https://www.amazon.com/" in Chrome.
2. Maximize the browser window.
3. Locate the Amazon search textbox.
4. Fetch the location and dimensions of the search textbox.
5. Check whether the textbox is enabled.
6. If enabled, enter "Selenium WebDriver" into it.
7. Otherwise, print "Search box is disabled".

## Q4. Write a working executable Selenium program to:

1. Open "https://www.youtube.com/" in Chrome.
2. Make the browser full screen/maximized.
3. Locate the YouTube logo.
4. Retrieve its position and size.
5. Verify whether the logo is displayed.
6. Check whether it is enabled/clickable.
7. If clickable, click the logo; otherwise, print "YouTube logo is not clickable"

## Q5. Write a working executable Selenium program to:

1. Open Google Chrome and navigate to "https://www.google.com/".
2. Locate the Google search textbox.
3. Retrieve the following properties:
   - X coordinate
   - Y coordinate
4. Check whether the textbox is displayed.
5. Check whether the textbox is enabled.
6. If enabled, enter "Selenium Automation" into the textbox.
7. Otherwise, print "Search textbox is disabled".

## Q6. Write a working executable Selenium program to:

1. Open "https://www.google.com/" in Chrome.
2. Maximize the browser window.
3. Locate the Google logo.
4. Retrieve its X, Y, width, and height.
5. Take a screenshot of the browser.
6. Check whether the Google logo is displayed.
7. If displayed, print "Google logo found" along with its location and size.
8. Otherwise, print "Google logo not found".
